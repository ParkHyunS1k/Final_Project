# Claude 블라인드 라벨 v1과 GitHub 이후 기록 비교

**AI(Claude Opus 5)가 쓴 라벨이다. 사람 검토 전이며 정답(gold)이 아니다.** 사람 라벨과 비교할 기준선, 그리고 "이후 기록을 그대로 정답으로 써도 되는가"를 확인하는 용도다.

## 절차

1. [GUIDELINES.md](GUIDELINES.md)에 판단 기준을 먼저 고정했다.
2. `candidates.jsonl`의 입력(발췌·기준 시각 업무 목록·참여자)만 보고 300건을 라벨링했다. `observed.jsonl`과 `selection.json`의 유형은 열지 않았다.
3. 라벨 파일 해시를 [LOCK.json](LOCK.json)에 기록한 뒤 기록을 열었다. [compare_observed.py](compare_observed.py)는 해시가 다르면 비교하지 않는다.

한계:
- `GH-TL-5382160561` 1건은 수집 단계에서 이후 기록을 먼저 본 사례다(`observed_seen_before_labeling=true`).
- 라벨 작성 중 기준 적용을 맞추려고 두 사례(개발 일지·작업 일지 게시물)를 무작업에서 제외로 고쳤다. 기록을 열기 전의 수정이다.
- 한 명(한 모델)의 라벨이라 일치율을 잴 수 없다.

## 비교 결과 (제외 47건을 뺀 253건)

| 항목 | 라벨 | GitHub 기록 | 겹침 |
|---|---:|---:|---:|
| 완료 (닫힘 COMPLETED) | 41 | 198 | 35 |
| 담당자 지정 | 2 | 36 | 0 |
| 새 업무 | 13 | 994 | 둘 다 있는 사례 3 |
| 진행 중·마감 | 39 | 대응 기록 없음 | — |

- 라벨이 금지한 변경 205개 중 **54개가 실제로 일어났다.**
- 기록에만 새 이슈가 생긴 사례가 134건이다. 대부분 같은 기간에 저장소에 등록된 무관한 이슈다.
- 서비스 종류로 대응시킬 수 없는 기록(다른 이유로 닫힘, 다시 열림, 담당자 해제, 제목 변경)이 82개다.
- 제외한 47건 중 25건에도 기록상 변경이 있었다. 기록만 쓰면 이 사례들이 정상 평가 사례로 섞인다.

### 댓글이 달린 이슈 자체의 완료

| | 라벨이 완료로 봄 | 라벨이 완료로 안 봄 |
|---|---:|---:|
| 48시간 안에 COMPLETED로 닫힘 | 35 | 52 |
| 닫히지 않음 | 4 | — |

라벨과 기록이 다른 52건을 닫힌 시점으로 나누면:

- **3분 안에 작성자가 닫음 17건.** 그중 3건은 "안 하기로 결정", "하지 않겠습니다", "다른 이슈로 통합"인데 COMPLETED로 닫혔다. 나머지 14건은 "PR만 올림", "staging 확인 후 닫겠다", "임시 로컬 작업 완료"처럼 문장은 미완료인데 바로 닫은 경우다. 다만 "fix하여 해결", "운영에서 12항목 모두 통과", "delegate로 y좌표를 제한함"은 원문만 봐도 완료로 볼 여지가 있어, **라벨 기준이 지나치게 엄격했을 수 있다.**
- **3분~1시간 안에 닫힘 11건.** "플래시 확인만 남음", "이슈를 열어 둔다"라고 쓴 직후 PR 병합이나 에이전트 자동 처리로 닫힌 경우가 많다. 원문에는 근거가 없다.
- **1시간 이후 닫힘 24건.** "MySQL 선택", "로그인 url은 /login", 질문 댓글처럼 원문과 무관하게 이후 작업으로 닫혔다.

반대로 "레벨 설정 및 레벨 랭킹 완료", "상품 목록 구현 완료"처럼 완료를 보고했는데 48시간 안에 닫히지 않은 사례가 4건이다.

## 결론

이후 기록은 **완료 판단의 참고 신호로는 쓸 만하지만 정답으로는 부족하다.** 완료는 라벨 41개 중 35개가 기록과 맞았다. 그러나 진행 중·마감은 기록에 없고, 담당자·새 업무는 거의 겹치지 않았으며, 취소·통합도 COMPLETED로 닫힌다. 기록을 정답으로 쓰면 원문 근거 없는 변경을 요구하게 되고, 금지한 오동작 54건이 오히려 정답이 된다.

사람 검토에서는 이 AI 라벨을 보여주지 않는다. 사람 라벨이 모이면 AI 라벨과의 일치율, 특히 위의 "지나치게 엄격했을 수 있는" 유형을 먼저 확인한다.

```sh
python3 datasets/github-timeline-candidates-v1/labels/compare_observed.py
```

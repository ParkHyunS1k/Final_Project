# GitHub 역할 분담·회의록형 후보 v1

**사람 검토 전 후보다. 정답(gold)이 아니다.** 역할 분담·담당 배정·회의 결정이 담긴 한국어 GitHub 댓글 50건과, 댓글 시각의 이슈 목록을 기록으로 복원한 상태를 담았다. 댓글 뒤 48시간 안의 실제 변경은 따로 저장했다. 수집일은 2026-09-11이다.

형식은 `github-timeline-candidates-v1`과 같다. 그 데이터셋에서 새 업무 13건·담당자 2건뿐이라 분담 평가 근거가 부족해 따로 모았다.

## 파일

| 파일 | 용도 |
|---|---|
| `candidates.jsonl` | 모델 입력 50건 |
| `observed.jsonl` | 이후 실제 변경. 정답이 아니다 |
| `selection.json` | 선정 방법·제외 수·사례 ID |
| `runs/search-2026-09-11/` | 수집 원본 163건 |
| `choose_review_set.py` | 풀에서 50건 선정 |
| `labels/` | AI 블라인드 라벨(작성 후 해시 잠금), 판단 기준, 이후 기록 비교 |

## 수집과 선정

`scripts/collect_github_timeline.py`에 기준 댓글 필터(`--anchor-regex`)를 추가해 실행했다.

- 검색식 10개: `역할 분담`, `역할분담`, `업무 분담`, `회의록 담당`, `담당자 배정`, `액션 아이템`, `맡겠습니다`, `맡아서`, `회의 결과`, `R&R` (모두 이슈, 대부분 댓글 있음).
- 기준 댓글은 분담·담당·맡다·액션 아이템·배정·어사인 표현을 포함해야 한다.
- 선정 제외: 기존 상태형 데이터셋 풀에 있던 저장소 33건, 보여준 업무 3개 미만 3건, 업무 목록 절반 이상이 회의록·스크럼·일지·스터디 게시물 15건, AI 도구 서명 6건.
- 저장소당 1건. 분담 표현이 많은 댓글을 먼저 골랐다(표현 3개 이상 5건, 2개 14건, 1개 31건). 2025년 이전 21건, 이후 29건.

|---|---:|

## 알려진 한계

- 분담 표현이 있어도 절반은 제안·질문·논의라 무작업이다. 확정된 분담은 13건 정도다.
- 학교 오픈소스 수업의 2인 미니 프로젝트가 많다. 대화체 분담은 흔하지만 업무 목록이 짧다.
- 한국어 이름과 계정 매핑이 원문에 거의 없다. 담당자 평가는 계정이 명시된 소수 사례에 의존한다.
- 대부분 저장소에 라이선스가 없다. 내부 평가용으로만 쓴다.

# 서비스 품질·출시 기준

연구 성능표가 아니라 사용자가 계획을 실행하고 기록을 신뢰할 수 있는지가 기준이다. 과거 모델 실험 계획은 archive/2026-09-07-eval.md에 보관한다.

## 2026-09-09 이후 필수 검증 (현재 규칙)

- 1인 시작 거절, 목표 편집 후 이전 동의로 시작 거절, 동시 시작 시 한 기한만 확정.
- 시작 후 목표·최종 기한을 일반 편집·AI 승인·되돌리기 어느 경로로도 변경 불가.
- 마감과 같은 시각 및 그 이후의 모든 쓰기를 저장 시점에서 거절, 부분 변경 없음.
- 체크인 0건이어도 결과물 전체 확인 시 완주 가능. 업무 전부 완료여도 결과물 미확인이면 거절.
- 종료 프로젝트의 멤버 내보내기 가능, 비멤버 거절, 다른 멤버 이메일 미포함.
- 개인별 가용시간·부가 업무 보류 API가 직접 요청해도 거절되는지.
- 업무 3단계·프로젝트 5단계 예약, 지난 단계 미생성, 밀린 단계는 최근 것만 발송.
- 완료·완주·참여 중단 시 남은 독촉 중단, 담당 변경 후 복귀 시 기발송 단계 미재발송.
- 실행기 2개 동시 실행 시 중복 발송 없음, 실패·불명확 응답 구분 기록, 업무 상태 불변.
- 원문 보존(공백·줄바꿈), 프로젝트 경계 검사, 원문 명령문 미실행.
- 모델의 없는 업무 ID·목표 변경·근거 불일치 거절, 생성만으로 DB 무변경.
- 부분 승인, 무권한 혼합 승인 전체 거절, 오래된 값 충돌, 재전송 중복 미적용.
- 되돌리기의 후속 수정 보호, 참조 있는 신규 업무 삭제 차단, 재전송 중복 방지.

이전 버전 기준은 아래에 남긴다. 가용시간·복구안·체크인 기반 완주 항목은 현재 규칙에서 제외됐다.

## 이전 버전의 필수 검증

- 저장 후 GET 및 새 세션에서 같은 상태 확인.
- 비멤버 프로젝트 조회·변경 불가, 멤버 간 동일 상태 공유.
- 이메일 불일치·만료·취소 초대 거절, 동시 가입 슬롯 중복 및 4명 초과 차단.
- 팀원은 본인 업무·가용시간만 수정, 팀장만 초대·최종 승인.
- 신규 프로젝트는 샘플 자동 생성 없음, 빈 업무로 완주 불가.
- 가용시간 0, 당일 선후행 작업, 시각 마감, 남은 공수 반영.
- 불가능한 복구안을 가능하다고 표시하지 않음.
- 오래된 제안, 동시 수정, 중복 승인 거절.
- 복구안 적용의 업무 변경·제안 처리·로그가 모두 반영되거나 모두 실패.
- 미참여·미체크인·증빙 누락·기한 경과 시 완료 차단.
- 상태 저장 실패 시 성공 표시 금지.
- 웹 타입 검사와 프로덕션 빌드. 관련 코드 린트.

## 파일럿에서 수집할 지표

핵심 결과물의 기한 내 검증 완료율, 병목 지속시간, 복구안 수락·수정·거절 및 실제 해소 여부, 일정 예측 오차, 관리에 드는 시간, 참여·완주 판정 이견.

아직 실제 팀 파일럿 결과가 없다. 단위·통합 테스트 수치를 완주 효과나 환급 정책의 공정성 근거로 쓰지 않는다. 자체 모델 학습이나 16셀 성능 실험은 서비스 출시 조건이 아니다.

- 후속 4단계: 업무 생성·편집·재배정·선행 작업 및 가용시간 재계산 검증. 순환/자기 참조/미가입 담당자 거절, 동시 쓰기, 의존관계 저장 실패 롤백 포함. 일정 10개 + API 통합 9개 통과. 로컬 화면에서 입력·편집·재접속 유지 확인.

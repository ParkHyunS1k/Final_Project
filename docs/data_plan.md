# 안전고리·안전난간 탐지 학습 데이터 계획

스코프: 사전학습 모델이 존재하지 않는 **안전고리**와 **안전난간** 두 대상을 AI Hub 데이터로 직접 학습한다.
README 2절 9종 중 **B-안전난간 미설치**와 **D-안전대 부착설비 미설치/고리 미체결**에 해당한다.

법령 RAG는 **타 팀 전담**이다. README 5절 [6][7], 9절의 조항 정확도·환각률, 15절 2·3번은 이 문서 범위 밖.

> 이 문서는 **계획과 결정**을 담는다. 실측 수치와 근거는 [`phase0_results.md`](phase0_results.md)에 있다.

### 하드웨어

맥북(M3 Pro 18GB)에서 YOLOv8s / 640 / batch 16 을 실제로 돌려 **12.7 img/s**를 측정했다.
4070은 약 110 img/s로 8~9배다.

| 용도 | 하드웨어 |
|---|---|
| 라벨 파싱, YOLO 변환, 소규모 sanity run, 추론·데모 | 맥북 |
| **본 학습, 하이퍼파라미터 탐색, seed 반복** | RTX 4070 |

원천 38 GB는 4070 데스크톱으로 직접 받는다. `scripts/download_aihub.sh`는 bash + curl만
있으면 리눅스/WSL에서 동작한다. 맥북에는 라벨 0.76 GB만 있으면 분석이 전부 된다.

> README 7절의 RunPod 4090 300 GPU시간 예산은 탐지에 쓸 필요가 없다. **VLM QLoRA로 돌린다.**
> 4070 12GB로는 VLM 1.7B(16GB)·4B(24GB) 파인튜닝이 불가능하며 거기가 GPU가 필요한 지점이다.

| 시나리오 | 클래스 | 개수 | 의미 |

## 2. 모델을 둘로 나누는 이유

Phase 0 교차표에서 확인된 사실이다.

```
             개구부  고소작업대   공통   로프   비계   사다리
SO-01 안전난간    0        0        0      0  58,614     0
WO-06 안전고리    0        0   36,454      0       0     0
```

두 파티션을 합쳐 단일 모델로 학습하면 **서로의 클래스가 라벨 없는 positive가 된다.**
공통 이미지에 안전난간이 찍혀 있어도 라벨이 없으므로 모델은 그것을 배경으로 학습한다.

클래스별 loss 마스킹으로 해결할 수 있으나 Ultralytics 기본 학습 루프는 지원하지 않는다.
**모델 2개로 분리한다.**

같은 이유로 **상황유형 필터도 필수다.** 같은 작업유형 안에서도 라벨 부착이 갈린다.

```
비계작업  UA 14,180프레임 → SO-01 0건 | UC 5,070 → 0건 | WS 6,916 → 6,464건
공통      UA 15,934프레임 → WO-06 4,041건 | WS 2,664 → 0건
```

거르지 않으면 19,250 프레임의 난간이 배경으로 학습된다.
`configs/data/targets.yaml`에 제약으로 박아 두었다.

### 3.3 실행

```bash

```

> **AI Hub 공식 `aihubshell`(v0.6)을 쓰지 않는다.** `merge_parts`가 병합에 실패하면
> 빈 파일을 만든 뒤 원본 part를 삭제하는데 종료코드가 0이라 조용히 넘어간다.
> 실제로 라벨 zip 52개 전량이 0바이트가 되는 것을 확인했다.
> `download_aihub.sh`가 직접 받아 직접 병합하고, 0바이트면 즉시 실패한다.

## 6. 절대 규칙 (README 8절)

- **프레임 단위 랜덤 분할 금지.** 반드시 영상 ID 단위로 분할한다.
  - 507 영상 ID: `H-210717_E01_E_WS-20_201` (파일명 끝 프레임 번호 제외)
  - 71407 영상 ID: `H-220609_G18_SO-42_001`
- 비율 train 70 / val 15 / test 15, 상황유형·촬영기기 층화
- 분할 스크립트와 seed를 커밋 (`src/data/split.py`, `data/yolo/*/split.json`)

> **seed 3회 반복 시 학습 seed만 바꾸면 안 된다.** 분할 seed도 함께 바꿔야
> 영상 배정의 분산이 지표에 반영된다. 영상이 15~36개뿐이라 이 분산이 크다.

## 8. 미해결 항목

| 항목 | 해결 방법 |
|---|---|
| `UC-01`(면적 0.1121) vs `UC-04`(0.1999)의 실제 차이 | 원천 확보 후 육안 확인 |
| `WO-06` 박스가 고리 자체인지 부착부 전체인지 | 원천 확보 후 육안 확인 |
| `guardrail`의 `negative_ratio: 0.15` 배경에 미라벨 난간이 있는지 | 원천 확보 후 육안 확인. 있으면 0으로 |
| 안전고리 영상 15개의 낮은 다양성 | group k-fold(k=5) + 외부 검증셋(SODA) 필수 |
| `class_mapping.yaml` 9종 확장 | Phase 0 교차표 기반으로 채울 수 있음 |

참석: Seedy(PM·QA), 윤프론트, 배백엔드, 한디자인

1. 완료 보고
- 윤프론트: React Native 앱 초기 설정 및 캐릭터 선택 화면 구현을 끝냈다. 캐릭터 선택 화면까지 시뮬레이터에서 동작 확인했고 PR도 머지했다.
- 배백엔드: PostgreSQL 사용 기록·캐릭터 성장·주간 리포트 데이터 모델 및 API 구현은 남은 공수 12시간이다.

2. 규모 재산정
- 숏폼 앱 사용시간 감지 및 캐릭터 오버레이 구현이 예상보다 훨씬 크다. iOS와 안드로이드 권한 체계가 달라서 남은 공수를 70시간으로 다시 잡는다.
- 지속 시청에 따른 단계적 오버레이 확대 및 햅틱 피드백 구현은 아직 시작 못 했다.
- 앱 사용시간 권한 요청 및 온보딩 안내 화면 구현은 거의 다 된 것 같다.

3. 마감 조율
- 숏폼 앱 사용시간 감지 및 캐릭터 오버레이 구현은 9월 22일까지 끝내기로 했다.
- 미션 보상 코인 및 캐릭터 꾸미기 아이템 구매 기능 구현은 9월 30일까지 미루자.

4. 인력 논의
- 사용 로그 기반 일일·주간 미션 추천 구현은 이번에 새로 합류하는 정테스트가 맡기로 했다.
- 핵심 사용자 흐름 통합 테스트 및 결함 수정은 16.3시간 정도로 본다.
- 반려동물 사진 On-device 픽셀 캐릭터 변환 구현은 난이도를 다시 보니 300시간짜리다.

5. 범위 관련 요청

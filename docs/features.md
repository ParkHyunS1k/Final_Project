# 서비스 기능과 운영 흐름

2026-09-08 결정: 목적은 서비스 개발. 현재 파일럿은 여러 프로젝트 생성, 목표 합의, 이메일 지정 초대 링크, 팀장·팀원 권한을 지원한다.

## 핵심 흐름

참여 약속 → 업무·가용시간 확인 → 체크인 → 일정 재계산 → 복구안 검토 → 승인 → 결과물 근거 → 완료 확인.

## 상태 관리

프로젝트, 작업, 의존관계, 날짜 가용시간, 체크인, 복구안, 변경 이력을 서버 D1에 저장한다. 사용자가 목표·필수 결과물·완료 기준·시작일·7~10일 기간을 입력해 생성한다. 마감은 마지막 날 오후 6시(Asia/Seoul)다. 기존 샘플은 소유자에게만 이관하고 새 계정에는 자동 생성하지 않는다. 신규 프로젝트는 업무가 없고 가용시간은 0시간으로 시작한다. 팀장이 업무 생성·편집·담당자 배정·선행 작업·필수/부가 여부를 설정한다. 참여 멤버만 담당자가 될 수 있고 자기 참조·순환 의존관계·보류 업무 참조를 거절한다. 완료·보류 업무는 편집하지 않는다.

모든 변경은 현재 버전을 전달한다. 다른 화면에서 먼저 수정했거나 제안 이후 상태가 바뀌면 409로 거절하고 최신 상태를 불러온다. 복구안은 한 번만 승인할 수 있다. 멤버인 계정은 같은 프로젝트를 읽고 비멤버는 조회·수정 모두 거절된다. 화면은 15초 간격과 창 포커스 복귀 시 갱신한다.

## 일정

- 날짜별 담당자의 가용시간을 명시적으로 저장한다. 기본 샘플은 각 2시간이며 사용자가 수정한다.
- 현재는 09:00부터 연속된 30분 단위 슬롯이다. 임의의 시작 시간·분할 시간대 입력은 미구현이다.
- 지난 슬롯과 마감 시각 이후 슬롯은 사용하지 않는다. 0시간은 배정하지 않는다.
- 업무는 남은 공수로 계산한다. 선행 작업 완료 후 같은 날 다음 작업을 배치할 수 있다.
- 완료된 업무는 다시 시간을 소모하지 않는다. 다시 진행할 때 남은 시간을 새로 받는다.
- 탐욕적 계획이며 최적화 해를 보장하지 않는다. 배치 불가는 ‘현재 계산상 불가’로 표현한다.

## 복구안

불가능한 계획에서 미완료 부가 기능을 큰 공수 순으로 보류해 계산한다. 다른 활성 작업의 선행 업무는 자동 보류하지 않는다. 핵심 기능은 자동 삭제하지 않는다. 부가 기능을 보류해도 불가능하면 실현 가능한 것처럼 제안하지 않고 범위·가용시간 재합의를 안내한다.

복구안은 생성 시점의 상태 버전과 대상 업무를 저장한다. 승인 시 최신 버전과 현재 시각으로 다시 검증한 후 업무·승인·로그를 함께 저장한다. 회의 제안은 이번 범위가 아니며, 반복 알림·자동 메시지도 없다.

## 완료와 보증금

작업 완료에는 결과물 링크 또는 직접 확인한 검증 기록이 필요하다. 시스템이 증빙 내용을 자동 검증하는 것은 아니다. 프로젝트 완료에는 참여 약속, 체크인, 모든 활성 작업의 근거, 기한 준수가 필요하다.

이용료 10만 원·보증금 20만 원은 기획 예시다. 결제·송금·실제 환급 판정은 미구현이며 완료 상태와 별개다. 팀원 이탈 시 개인 기여를 보호할 정책과 운영자 검토·이의제기는 유료 출시 전에 확정한다.

## 초대와 권한

팀장은 이메일에 묶인 7일 유효 초대 링크를 생성·취소한다. 이메일은 발송하지 않는다. 서버에는 토큰의 SHA-256 해시만 저장한다. 초대 이메일로 로그인하고 목표에 동의해야 팀원으로 참여한다. 취소·만료·이미 처리된 링크는 거절한다. 동시 가입은 버전과 고유 팀원 슬롯으로 보호하며 최대 4명이다.

팀원은 본인 업무·가용시간만 변경하고 팀장은 전체 변경, 복구안 승인·거절, 완주 확인을 수행한다. 초대 대상 이메일 목록은 팀장에게만 공개한다.

현재 Sites는 소유자 전용이다. 실제 외부 팀원에게는 사이트 접근 권한도 별도로 필요하다. 프로젝트 초대 링크가 플랫폼 접근 권한을 자동으로 부여하지 않는다. 실제 두 계정 브라우저 협업 검증은 아직 남아 있다.

## 노션형 작업 공간 1차

프로젝트 사이드바를 통해 프로젝트 업무·내 할 일·스프린트 현황·프로젝트 문서·팀 가용시간·완주 확인으로 이동한다. 기본 진입 화면은 업무 표이며 보드와 동일한 데이터를 사용한다. 상태는 시작 전/진행 중/완료/다음 스프린트로 표시하고, 완료에는 근거 입력이 필요하다. 업무 상세 패널에서 설명·상태·공수·선행 작업·체크인·완료 근거를 확인한다. 프로젝트 문서는 현재 목표·결과물·완료 기준 조회와 초대 관리이며 자유 문서 편집은 다음 단계다.

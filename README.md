# 사업주 안전조치 의무 이행 검증 시스템

영상 기반 산업안전보건법 위반 판정 및 법령 근거 리포팅 · 온프레미스 구현
부트캠프 파이널 프로젝트 · 13주

---

## 0. 이 문서의 역할

프로젝트의 모든 결정 사항이 여기 있다. 작업 전 반드시 읽고, 여기 명시된 제약을 어기지 말 것. 판단이 필요한 상황에서 이 문서와 충돌하는 방향이 보이면 진행하지 말고 먼저 물어볼 것.

## 1. 프로젝트 정의

### 한 줄 요약

**영상으로 산업안전보건법상 사업주의 안전조치 의무 이행 여부를 검증하고, 미이행 시 조항 근거와 법적 리스크를 명시한 리포트를 자동 생성한다.**

### 왜 "사업주 의무"인가

산업안전보건기준에 관한 규칙은 조문이 거의 예외 없이 다음 형태다.

> 사업주는 ~하여야 한다
> 사업주는 근로자가 ~하지 않도록 할 것

행동을 규정한 제67조, 제68조조차 의무 주체가 사업주다. 제재도 사업주는 형사처벌(5년 이하 징역 또는 5천만원 이하 벌금), 근로자는 과태료 5만원(1차)으로 비중이 다르다.

**따라서 이 시스템의 출력은 개인 지목이 아니라 "이 구역에서 해당 의무가 이행되지 않고 있다"이다.** 설비 미설치와 근로자 위험 행동이 모두 사업주 의무 미이행의 증거로 수렴한다.

| 관측 | 의무 미이행의 종류 |
|---|---|
| 안전난간이 없다 | 방호 조치를 하지 않았다 |
| 작업자가 난간을 딛고 있다 | 그렇게 하지 않도록 관리하지 않았다 |
| 안전대 걸 곳이 없다 | 부착설비를 설치하지 않았다 |
| 안전모를 안 썼다 | 지급하고 착용시키지 않았다 |

### 핵심 가설

**객체의 유무만으로는 법령 위반을 판정할 수 없다.** 같은 탐지 결과라도 작업 맥락이 판정을 가른다.

### 프로젝트의 결론이 될 실험

맥락 의존도가 다른 네 그룹에서 룰 기반 대비 VLM 판정의 개선폭이 얼마나 다른가. 낮은 그룹에서는 차이가 작고 높은 그룹에서는 커야 한다. 이 곡선이 "맥락 판정이 왜 필요한가"를 데이터로 증명한다.

성능 수치 자체가 목표가 아니다. 최신 연구도 유사 과제에서 F1 50퍼센트대다.

## 3. 법령 체계와 제재 구조

### 조항 위계

```
안전보건규칙 제13조, 제32조, 제42조, 제43조, 제44조, 제56조, 제67조, 제68조
  → 산업안전보건법 제38조 (안전조치)
    → 제168조 (벌칙)
```

### 제재

| 대상 | 근거 | 제재 |
|---|---|---|
| **사업주** | 산안법 제38조 위반 | **5년 이하 징역 또는 5천만원 이하 벌금** |
| 사업주 | 제38조 위반으로 근로자 사망 | 7년 이하 징역 또는 1억원 이하 벌금 |
| **근로자** | 산안법 제40조 위반 | 300만원 이하 과태료 (시행령 별표 35 기준 1차 5만원) |

> **중요: 안전조치 의무 위반은 과태료가 아니라 형사처벌이다.** 리포트에 "과태료"라고 쓰지 말 것. 근로자 과태료가 명확한 것은 보호구 미착용(제40조)뿐이다.

### 주요 조항의 정량 기준

| 조항 | 기준 |
|---|---|
| 제13조 안전난간 | 상부 난간대·중간 난간대·발끝막이판·난간기둥 4요소. 상부 난간대 90cm 이상, 발끝막이판 10cm 이상 |
| 제56조 작업발판 | 폭 40cm 이상, 발판재료 간 틈 3cm 이하, 둘 이상 지지물에 고정 |
| 제67조 말비계 | 기울기 75도 이하, 미끄럼 방지장치, 양측 끝부분 작업 금지 |
| 제68조 이동식비계 | 바퀴 고정 또는 아웃트리거, 최대 적재하중 250kg, 안전난간을 딛거나 받침대·사다리 사용 금지 |
| 제44조 안전대 부착설비 | 높이 2m 이상 장소 |
| 제43조 개구부 | 안전난간·울타리·수직형 추락방망·덮개 중 하나 + 개구부 표시 |

> **단안 영상에서 길이 실측은 불가능하다.** 90cm, 40cm, 3cm 같은 정량 기준의 직접 검증은 범위 밖으로 두고 **구성 요소의 존재 여부만 판정**한다. 이 한계를 문서에 명시할 것.

## 4. 리포트 출력 형식

> **2026-08-25 결정: 실시간 경보를 버리고 업로드 기반 리포트로 간다.**
> 사용자가 현장 사진을 올리면 안전시설 미흡 지점을 찾아 위반 사항·조항·법정형을
> 담은 리포트를 낸다. 근거와 남은 리스크는 `docs/HANDOFF.md`(로컬 전용, 저장소에 없음) 3.⓪.

**1단계는 사진만 받는다.** 영상은 같은 위반이 프레임마다 중복 보고되므로 이벤트
단위 중복 제거(9절 참조)가 선행돼야 한다. 그 전까지 영상 입력을 열지 않는다.

```
촬영 일시    2026-09-14 14:23  (EXIF, 없으면 "미상")
사진         site_3dong_5f_west.jpg  (전경 1 + 근접 1 쌍)
지점         사용자가 지정한 구역 #2 (5층 서측 단부)

관측 사실    작업발판 단부에 안전난간 구성요소가 확인되지 않음
             상부 난간대  미확인
             중간 난간대  미확인
             발끝막이판  가려짐 (판정 불가)
             난간기둥    확인됨
대체 방호조치 울타리·수직형 추락방망·덮개 모두 미확인
신뢰도       중 — 발끝막이판이 가려져 있어 4요소 중 1개를 판정하지 못했다

위반 조항    안전보건규칙 제13조, 제43조
상위 근거    산업안전보건법 제38조(안전조치)
사업주 리스크 5년 이하 징역 또는 5천만원 이하 벌금
             (근로자 사망 시 7년 이하 징역 또는 1억원 이하 벌금)
권고 조치    안전난간 설치 또는 추락방호망 설치 (제42조 단계적 조치)
```

**"관측 사실"과 "위반 조항"을 반드시 분리한다.** 모델은 본 것만 말하고, 조항 연결은 RAG가 하고, 최종 판단은 사람이 한다.

**리포트가 지켜야 할 것 — 리포트 제품이 되면서 새로 생긴 요구다.**

1. **판정을 4요소로 쪼개 낸다.** 조항을 걸려면 어느 부품이 빠졌는지 말해야 한다.
   상부 난간대 / 중간 난간대 / 발끝막이판 / 난간기둥, 각각 `확인됨 / 미확인 /
   가려짐`. 507 정답은 이진뿐이므로 **사람 라벨링이 필수 경로**다 (9절).
2. **대체 방호조치 확인란은 생략할 수 없다.** 제43조는 개구부에 안전난간·울타리·
   수직형 추락방망·덮개 중 **하나**를 인정한다. 덮개가 있으면 난간이 없어도
   적법이다. **"난간 없음 → 위반" 은 성립하지 않는다.**
3. **판정 불가를 위반으로 쓰지 않는다.** 가려짐·화질 부족·각도는 별도로 표기하고
   수동 검토 큐로 보낸다. 채점 규칙은 9절에서 미리 고정한다.
4. **"예상 과태료" 를 쓰지 않는다.** 사업주 안전조치 의무 위반은 과태료가 아니라
   **형사처벌**이다(3절). 법정형을 그대로 인용한다.
5. **유리 외장 건물을 주의한다.** 유리 커튼월에 비친 비계를 실물로 보고한 사례가
   실측으로 확인됐다 — A04 미매칭 검출의 55.4%다 (`docs/train_results.md` 1.8).
   반사를 실물로 보고하면 리포트 신뢰가 무너진다.

**개인 식별 정보를 저장하지 않는다.** 얼굴은 블러 처리하고 리포트는 개인이 아닌 구역 단위로 작성한다.

## 5. 아키텍처

**시간 제약이 없어졌다.** 이미지당 1~3초를 감수할 수 있으므로 1차(실시간 룰) /
2차(비동기 VLM) 계층 분리가 사라진다. 대신 **"어느 지점을 VLM 에 물을 것인가"**
가 유일한 설계 축이 된다.

```
사진 입력 (전경 + 근접 쌍)
  → [1] 지점 선정  ← 아래 세 후보 중 하나. 미확정
  → [2] 구조화 프롬프트 생성
  → [3] 로컬 VLM 4요소 판정 (Qwen2.5-VL 7B, Apache-2.0)
  → [4] 대체 방호조치 확인
  → [5] 법령 retriever 그라운딩
  → [6] 조항 실재 검증 (국가법령정보 API 재조회)
  → 리포트 (판정 불가 항목은 수동 검토 큐로)
```

### [1] 지점 선정 — **미확정. 같은 정답셋에서 세 조건을 비교한다**

| 후보 | 내용 | 위험 |
|---|---|---|
| 전체 이미지 | 사진 한 장을 통째로 VLM 에 준다 | 작은 난간이 묻힌다 |
| 멀티스케일 타일 | 겹치는 격자로 잘라 모든 타일을 묻는다 | 전역 맥락이 잘리고, 시설이 타일 경계에 걸리고, 중복 보고와 FP 가 누적된다 |
| 제안기 + VLM | 탐지기가 후보 지점을 내고 VLM 이 판정 | 1단계 회수율 27~59%가 상한이 된다 |

> **제안기를 만든다면 난간이 아니라 단부·개구부·작업발판을 찾아야 한다.**
> 찾아야 하는 것은 **난간이 없는 곳**인데, 난간 탐지기는 그런 위치를 제안할 수
> 없다. 지금의 `guardrail` 탐지기를 그대로 제안기로 쓰면 논리가 앞뒤가 안 맞는다.

**ROI 를 누가 만드는가는 제품 전환으로 해소되지 않았다.** 사진은 **장면**을
지정할 뿐 "난간이 있어야 하는데 없는 지점" 을 지정하지 않는다. 13주 안에서는
**사용자가 화면에서 지점을 찍는 UI**(지정 ROI)를 전제로 한다
([`docs/eval_protocol.md`](docs/eval_protocol.md) 3.1).

### 촬영 가이드 — 제품 제약으로 쓴다

난간이 화면에서 클수록 탐지가 잘 되는 것은 paired 비교로 확인됐다
(`docs/train_results.md` 1.7). "가까이 찍어 주세요" 를 촬영 가이드로 건다.
**단 근접 사진만 받으면 안 된다** — 높이·단부·대체 방호조치 맥락이 잘린다.
**전경 + 근접 쌍**을 받는다. 크기 창을 제품 제약으로 확정하려면 하한뿐 아니라
**상한**도 정해야 한다 (면적비 0.20 이상에서 효과가 뒤집힌다).

## 8. 절대 규칙

### 데이터 분할

> **프레임 단위 랜덤 분할 금지.** 인접 프레임은 거의 동일하므로 train과 test에 나뉘어 들어가면 성능이 크게 부풀려진다. 반드시 **영상 단위 또는 촬영 세션 단위**로 분할한다.

- 비율: train 70 / val 15 / test 15
- 층화 기준: 위반 유형, 촬영 시점(CCTV / 안전모캠 / 액션캠)
- 각 split에 세 촬영 시점이 모두 포함되도록 구성
- 분할 스크립트와 seed를 저장소에 커밋할 것

### 데이터 다운로드

> **AI Hub 데이터를 전량 다운로드하지 말 것.**

샘플(경량) 데이터와 파일 목록 API 다운로드가 제공된다. 9종에 해당하는 클래스만 선택 확보한다. 20-30GB면 충분하다.

### 외부 API

> **운영 아키텍처는 100퍼센트 로컬이다.**

외부 API는 실험 3에서 평가셋 수백 건에 대한 **1회 추론에만** 사용한다. 학습과 운영 파이프라인에는 일절 사용하지 않는다. 호출 경로는 `src/eval/experiments/` 아래로만 격리한다.

### 재현성

- 모든 실험은 **seed 3회 이상 반복**하고 평균과 표준편차로 보고한다
- 단순 baseline을 먼저 만들고 최종 모델의 개선폭을 제시한다

### 스코프

- 게이트 미달 시 정해진 축소안을 따른다. 임의로 일정을 늘리지 않는다
- W12 이후 신규 기능 및 신규 위반 항목 추가 금지

## 9. 평가 설계

> **2026-08-25 갱신.** 리포트 제품 전환에 맞춰 다시 썼다. 실시간 알람 지연은
> 지표에서 빠지고, 지점 단위 판정과 판정 불가 처리가 들어왔다.
> 무엇을 어떻게 재고 무엇을 주장할 수 있는지는
> [`docs/eval_protocol.md`](docs/eval_protocol.md) 가 정본이다.

### 기준 A — 박스 지표 (A, B 그룹)

- mAP@0.5, mAP@0.5:0.95, **클래스별 AP 필수 보고**
- **집계는 현장 macro.** 프레임 가중은 대조값으로 쓰지 않는다 (AP 는 비선형)
- PR 곡선으로 임계값 선택하고 근거 기술

> **`guardrail` 은 이미 이 기준에 미달했다** — site-macro 0.559, `guardrail` AP
> 0.365, 외부(71407) 0.02. **이 미달은 지우지 않는다** (`docs/train_results.md` 1절).

### 기준 B — 지점 단위 미설치 판정 (**주지표**)

박스 mAP 는 제품 질문("이 지점에 규정 난간이 있는가")과 단위가 어긋난다.
그래서 지점 단위 기준을 **추가로** 둔다.

- **집계는 클립/사진 macro.** 지점으로 나누면 큰 사진이 지표를 지배한다
  (적발률이 지점 가중 90.1% 대 클립 macro 72.5%로 갈렸다)
- **분모가 독립 표본인지 먼저 확인한다.** 인접 프레임은 독립이 아니다
- 신뢰구간은 클립 단위 bootstrap
- **퇴화 해에서 무슨 값이 나오는지 반드시 함께 보고한다** — "전부 present"
  퇴화가 F1 0.846 / J −0.006 을 낸 사례가 있다

### 요소 단위 판정 (리포트 본체) — **판별 2요소만 채점한다**

> **2026-08-25 크롭 육안 확인 결과** (`docs/train_results.md` 1.9, 53장/36클립/4현장):
> **발끝막이판은 네 현장 어디에도 설치돼 있지 않고**(A08 은 구역 폭 1,000px 이
> 넘는데도 없다), **난간기둥은 정상·미설치 양쪽에 있다.**
> **4요소 중 판별에 쓰이는 것은 상부 난간대·중간 난간대 둘뿐이고 나머지 둘은
> 퇴화 상수다.**

| 요소 | 정상(`SO-01`) | 미설치(`UC-01`) | 판별력 |
|---|---|---|---|
| 상부 난간대 | 있음 | 없음 | **있다** |
| 중간 난간대 | 있음 | 없음 | **있다** |
| 난간기둥 | 있음 | **있음** | 없다 |
| 발끝막이판 | **없음** | 없음 | 없다 |

**따라서 제13조를 엄격히 적용하면 `SO-01` 구역도 전부 위반이다.**
"`SO-01` = 적법" 이라는 전제가 성립하지 않는다.

**결정 (2026-08-25): (a) 판별 2요소만 채점한다.**

| 안 | 내용 | 판단 |
|---|---|---|
| **(a) 판별 2요소만 채점** | **상부·중간 난간대만 채점**하고 난간기둥·발끝막이판은 리포트 표시용 | **채택.** 상수를 빼면 지표가 부풀지 않는다 |
| (b) 4요소 전부 채점 | 상수 2개를 명시하고 퇴화 기여를 분리 보고 | 기각 — 요소별 평균 정확도가 근거 없이 올라간다 |
| (c) 법령대로 엄격 채점 | 발끝막이판 없으면 위반 | 기각 — `SO-01` 이 전부 위반이 되어 데이터셋 라벨과 어긋난다 |

**대가를 명시한다.** "법령 4요소를 판정한다" 고 말할 수 없다. 채점하는 것은
**상부·중간 난간대 두 요소**이고, 나머지 둘은 **관측 결과로 표시하되 채점하지
않는다.** 발표와 논문에서 이 구분을 흐리지 않는다.

**어느 안이든 리포트에서는 관측 사실과 법령 판정을 분리해 쓴다** (4절).
"상부·중간 난간대 확인됨 / 발끝막이판 미확인" 은 관측이고, 그것이 위반인지는
조항 연결이 판단한다.

**측정할 때 지키는 것** — 스키마와 무관하게 유지된다.

- 요소별 정확도와 **전 요소 동시 정답률**을 함께 낸다
- **면적·종횡비 metadata baseline 을 반드시 병기한다.** `SO-01` 면적비 중앙값
  0.0579 대 `UC-01` 0.1111 로 2배 차이가 난다. 크롭 크기만 쓰는 분류기가 몇 점을
  내는지 재 두지 않으면 **VLM 이 난간 구조를 본 것인지 크롭 크기를 본 것인지
  구분할 수 없다**
- **대체 방호조치(울타리·수직형 추락방망·덮개) 확인란**을 정답 스키마에 넣는다
- **판정 대상에 면적 하한을 건다.** A17 미설치의 최소 면적대는 100×415px 같은
  세로 슬리버로 "비계 한 칸" 이 아니다. 현재 하한 0.10 은 측정값이 아니라
  하드코딩 경계이므로 **근거를 만들어 다시 정한다**

### 판정 불가 처리 — **모델을 돌리기 전에 고정한다**

`가려짐` · 화질 부족 · 각도를 **오경보 / 미탐 / 수동 검토** 중 무엇으로 셀지
결과를 보기 전에 정한다. 그러지 않으면 결과에 규칙을 맞추게 된다.

- 권장안: **수동 검토 큐로 분리하되 기권 예산을 사전 고정**한다
- 기권 판단 점수와 **그 임계를 정할 calibration 집합**도 함께 고정한다
- calibration 을 어디서 뗄지는 미결이다 — 기준 B 는 현장이 3곳뿐이라 하나를
  떼면 평가가 2곳으로 준다 (`docs/eval_protocol.md` 3.5)

### 리포트 지표 (C, D 그룹 포함)

- 위반 판정 F1 — **난이도 3계층별, 그룹별로 분리 보고**
- 조항 정확도 — 조·항·호 번호를 정규식으로 자동 채점
- **환각률 (실재)** — 인용 조항을 법령 API로 재조회해 실재하지 않는 조항 인용 비율.
  **리포트 제품에서는 주변 기능이 아니라 핵심 의존성이다.** 법령 RAG 는 타 팀이므로
  인터페이스와 실패 시 동작을 먼저 합의할 것
- **오적용률 (신설 2026-08-25)** — **실재하지만 적용되지 않는 조항을 인용한 비율.**
  실측으로 확인됐다: 안전모 미착용 쿼리에 규칙 제32조(맞음)와 **제572조(방열복·방한복,
  틀림)** 가 함께 왔고 **둘 다 `[API 검증 완료]` 로 찍혔다** (`docs/train_results.md` 5.1).
  **조항 실재 ≠ 조항 적용 타당성.** 위 환각률만으로는 이 실패를 못 잡는다.
  사용자는 "검증 완료" 를 신뢰하는데 검증된 것은 **존재**뿐이다
- **중복 보고율** — 같은 지점을 몇 번 보고했는가. 영상 입력을 여는 조건이다
- 설명 품질 — BERTScore (선행 연구와 동일 지표)

> 조·항·호는 정규식으로 정확히 채점 가능하다. **LLM-as-judge에 의존하지 않는 설계**이며 이 점을 발표에서 강조한다.

| 조항 정확도 | 0.80 | 0.90 |
| 환각률 (실재) | 10퍼센트 이하 | 3퍼센트 이하 |
| **오적용률** (신설) | **미정 — 먼저 측정한다** | |
| 라벨러 kappa | 0.60 | 0.75 |

> **1차 알람 지연 항목은 삭제했다** — 실시간 경보를 버렸으므로 의미가 없다.
> 대신 **사진 1장당 처리 시간**을 기술통계로 보고한다 (합격 기준 아님).

> **2026-08-25 VLM 파일럿 — 오경보율은 해결됐고 적발률이 남았다.**
> 같은 구역 paired 로 VLM 오경보가 A17 4.8% / A04 4.2% / A21 0.0% 다
> (YOLO 는 38.1 / 57.5 / 66.7%). **세 현장 전부 오경보 기준(≤20%)을 통과**하지만
> **적발에서 미달**한다 (72.2 / 0.0 / 11.1%). `docs/train_results.md` 1.10.

> **현재 기준 B 실측은 세 현장 모두 오경보율에서 미달이다** (39.0~66.2%).
> 그리고 **네 현장과 71407 은 전부 development set 이므로 합격 선언에 쓸 수 없다**
> (`docs/eval_protocol.md` 4.4). 합격 판정에는 의사결정에 전혀 쓰지 않은 현장이
> 필요하다.

### 정답 라벨링 — **미룰 수 없는 필수 경로. 단 스키마 확정이 선행한다**

507 정답은 이진(`SO-01` / `UC-01`)뿐이다. 요소 단위 출력을 채점할 정답이 **없다.**

규모 200-300장. 9종 대상에 한정.

라벨 항목: 작업 유형 / 위반 유형 / **요소별 확인됨·미확인·가려짐**(어느 요소를
채점할지는 위 스키마 결정에 따른다) / **대체 방호조치 유무** / 적용 조항 /
위험 등급 / 난이도(명백·경계·모호)

**필수 조건** — 같은 객체 상태인데 맥락에 따라 판정이 갈리는 케이스를 의도적으로 포함할 것.

**표집 조건 — 실측으로 정해졌다** (`docs/train_results.md` 1.9).

- **A21 을 반드시 포함한다.** A17·A04 의 미설치는 "기둥만 남음 / 바깥쪽 전무" 라
  명백하지만, **A21 은 비계 프레임의 다음 층 가로재가 보여서 "이 발판 위 90cm 에
  난간대가 있는가" 를 따져야** 한다. 쉬운 두 현장만으로 재면 **kappa 가 부풀려진다**
- 랜덤이 아니라 **현장 × 정상/미설치 × 클립 × 면적대**로 층화한다
- **면적 하한 미만의 슬리버 구역은 제외한다** (A17 최소 면적대는 100×415px 다)
- **A04 미설치는 클립 2개뿐**이다. 구역을 많이 뽑아도 표본이 늘지 않는다

2. **제44조는 높이 2m 이상이 전제다.** 단안 영상에서 높이 판정이 어려우므로 고소작업 데이터셋 특성상 대부분 해당한다고 가정하고, 높이 검증은 범위 밖으로 명시한다.

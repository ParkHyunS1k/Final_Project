[ProjectMate 7일 스프린트 킥오프 회의록]

목표: 네 명이 프로젝트 생성부터 업무 변경안 검토까지 실제 흐름을 완주한다.
업무 분담:
- 이프론트(프론트엔드): 프로젝트 생성 화면과 목표 합의 UI를 구현한다. 예상 공수 8시간.
- 박백엔드(백엔드): 프로젝트·초대·업무 API와 D1 저장을 구현한다. 예상 공수 10시간.
- 최디자인(UX 디자인): 핵심 화면 wireframe과 상태별 안내 문구를 작성한다. 예상 공수 6시간.
- 김리드(PM·QA 팀장): acceptance criteria를 정리하고 전체 흐름을 QA한다. 예상 공수 5시간.
의존성: 화면 연결은 API 응답 형식이 확정된 뒤 진행하고, 통합 QA는 세 구현 결과가 모인 뒤 시작한다.
